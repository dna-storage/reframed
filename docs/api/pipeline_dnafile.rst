File-Level Pipeline API (``dnastorage.system.pipeline_dnafile``)
================================================================

High-level file I/O interface for encoding an entire file to DNA and decoding
it back. Use this API when working with real files end-to-end. For
programmatic / simulation use where you control the strand list directly,
use the builder functions in :mod:`dnastorage.arch.builder` instead.
