Pipeline Builders (``dnastorage.arch.builder``)
================================================

Factory functions that construct complete encode/decode pipelines. Each builder
takes a ``packetizedfile`` object as its first argument and keyword parameters
that control codec behaviour. Parameters are forwarded from JSON config files
during simulation runs and from direct Python calls during library use.
